# getting started

shadlet is a python-first framework. you write python; shadlet manages the frontend, communication, and rendering.

## prerequisites

- python 3.11 or newer

node.js 24 and npm are needed only when building the renderer from source.

## install

```bash
uv pip install -e '.[dev]'
```

or with pip:

```bash
pip install -e '.[dev]'
```

verify:

```bash
shadlet doctor
```
