# getting started

shadlet is a python-first framework. you write python; shadlet manages the frontend, communication, rendering and packaging.

## prerequisites

- python 3.11 or newer
- node.js 20 or newer
- npm

## install

```bash
uv pip install -e '.[dev]'
```

or with pip:

```bash
pip install -e '.[dev]'
```

verify:

```bash
shadlet doctor
```
