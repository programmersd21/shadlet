# component catalogue

shadlet provides the following shadcn/ui-based components. This list describes
the current shadlet API and does not imply parity with the complete upstream
catalogue.

`direction`, `scroll-area`, `sonner`, and `toast` are exposed through the
renderer module set: `DirectionProvider` wraps direction-sensitive content,
`ScrollArea` is available from `shadlet.layout`, and `Toast` uses the sonner
runtime used by `Context.toast`. See the generated
[compatibility matrix](compatibility-matrix.md) for the exact per-component
runtime and verification status.
